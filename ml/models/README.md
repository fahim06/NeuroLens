# ML Models Directory

This directory stores trained ML models for inference.

## Supported Formats

- `.keras` - Keras model format
- `.h5` - HDF5 format (legacy)
- SavedModel directory

## Model Placement

Place model files here and configure the path in settings or environment variables.

## Current Models

- `baseline_mariya.keras` - Located in `assets/` directory

## Notes

- Models should not be committed to version control if they are large
- Use model versioning for production deployments
